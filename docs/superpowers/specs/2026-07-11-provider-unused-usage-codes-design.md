# 端点未使用使用码明细设计

日期：2026-07-11  
范围：管理员 API 配置页，查看某端点「未使用」额度对应的使用码明细  
状态：已确认

## 背景

当前 API 配置下拉中，每个端点右侧显示「未使用 N」。  
该数字是所有使用码在该端点上的剩余额度合计。

管理员需要进一步查看：

- 这些剩余分别属于哪些使用码
- 显示使用码备注名
- 按剩余从高到低排序

## 目标

管理员点击端点行的「未使用 N」后，弹出明细层，列出该端点下仍有剩余的使用码。

## 非目标

- 不在明细中编辑额度
- 不新增搜索、筛选开关
- 不展示「已用 / 总配额」三列
- 不展示该端点剩余为 0 的使用码
- 不新增后端接口

## 入口与权限

- 位置：设置 → API 配置 → 端点列表行右侧「未使用 N」
- 角色：仅管理员
- 点击「未使用 N」打开明细
- 点击事件阻止冒泡，不切换当前选中端点
- 「未使用 0」也可点击，进入空态

## 展示形态

### PC

- 形态：锚定在「未使用 N」附近的 popover
- 关闭：点击外部、Esc、再次点击触发点

### 移动端

- 形态：底部抽屉（bottom sheet）
- 最大高度约 70vh，列表可滚动
- 关闭：点击遮罩、下滑关闭、关闭按钮

## 面板结构

1. 标题：`{端点显示名}`
2. 副标题：`未使用合计 N`
3. 使用码列表
4. 可选底部统计：`共 X 个使用码`

## 列表规则

### 数据字段

- 备注名：`usageCode.name`
- 图片端点剩余：`providerRemainingImageCredits[profileId]`
- 视频端点剩余：`providerRemainingVideoCredits[profileId]`
- 端点类型：`profile.apiMode === 'videos'` 时读视频剩余，否则读图片剩余

### 纳入条件

同时满足：

1. 使用码有权使用该端点  
   - `allowedProviderProfileIds == null`（全开），或  
   - 数组包含该 `profileId`
2. 该端点剩余为 `null`（不限）或 `> 0`

### 排除条件

- 该端点剩余为 `0`
- 未授权该端点

### 排序

1. 剩余为 `null`（不限）排最前
2. 其余按剩余数字降序
3. 剩余相同则按备注名 `localeCompare` 升序

### 行展示

- 左侧：使用码备注名  
  - 主字段为 `name`  
  - 若备注名为空，回退显示使用码本身的脱敏/原文（与现有管理端使用码展示习惯一致）  
  - 单行省略，完整名称放 `title`
- 右侧：
  - `null` → `不限`
  - 数字 → 原样显示

### 空态

文案：`该端点暂无剩余额度的使用码`

## 交互边界

- 点击列表行只查看，不跳转、不修改、不切换 API
- 明细层层级高于 API 配置下拉
- 打开明细不得改变当前选中端点
- 关闭明细后，端点下拉状态保持可继续操作

## 实现落点

### 前端

- 主要改动：`src/components/SettingsModal.tsx`
- 建议抽取纯函数（可放同文件或 `src/lib/`）：
  - 输入：使用码列表、端点 `profileId`、`apiMode`
  - 输出：过滤并排序后的明细项
  - 字段建议：`id`、`name`、`remaining`（`number | null`）

### 后端

- 无改动
- 复用现有管理员使用码统计字段

## 验收标准

1. 管理员点击某端点「未使用 N」可打开明细
2. 明细只包含该端点剩余 `> 0` 或不限的使用码
3. 不限排在最前，其余按剩余降序
4. 每行显示备注名与剩余
5. 合计数字与端点行「未使用 N」一致
6. 点击明细不切换端点
7. PC 为 popover，移动端为底部抽屉
8. 无剩余时显示空态
